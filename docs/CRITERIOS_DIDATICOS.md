# CRITÉRIOS DIDÁTICOS

1. **Exemplo pequeno antes da integração.** Cada recurso aparece primeiro de forma isolada e depois sobre dados do banco.
2. **Repetição com propósito.** As atividades repetem operações para fixação, mas também pedem comparação, diagnóstico e escolha de estrutura.
3. **Banco como fonte, não como magia.** `fetchone()`/`fetchall()` materializam dados em memória; estruturas Python não ficam sincronizadas automaticamente.
4. **Domínio único e simplificado.** Toda a prática usa uma rede varejista fictícia com lojas/CDs, produtos, estoque, canais, pedidos, reposição, categorias e rotas. Não há tabelas apenas decorativas.
5. **Estrutura escolhida pelo problema.** O aluno deve perceber quando ordem, unicidade, acesso por chave, FIFO, LIFO, prioridade, hierarquia ou conectividade justificam estruturas diferentes.
6. **Atividades sem solução.** Cada arquivo em `exercicios/` contém somente o enunciado e espaço para o aluno escrever a solução.
